User Interface Package¶

class user_interface.account_details_window.AccountDetailsWindow(account: BankAccount)¶

A class used to display account details and perform bank account transactions.

on_apply_transaction()¶

Handles the deposit or withdrawal transaction. If the transaction is valid, it updates the balance. If the transaction fails, shows an error message.

on_exit()¶

Closes the AccountDetailsWindow and returns the user to the previous window.

class user_interface.client_lookup_window.ClientLookupWindow¶

Description: This class handles the client lookup functionality within the banking application. It allows the user to search for a client by their client number and view their associated accounts. Author: Vandana Bhangu

apply_account_type_filter(account_type: str)¶

Apply a filter on account type (e.g., Savings, Checking).

apply_balance_filter(balance_threshold: str)¶

Apply a filter based on the account balance.

on_apply_filter()¶

This method applies the filter to the accounts table based on the selected account type and filter criteria (e.g., balance or account number).

on_lookup_client()¶

This method handles the client lookup process. It retrieves the client number from the input field, checks if it’s valid and exists, and displays the associated client and account information.

on_reset_filter()¶

This method resets the applied filter, clears the filter field, and makes all rows visible again.

reset_display()¶

This method resets the display, clearing the client information and the account table.

show_message(title: str, message: str) → None¶

Helper method to show a QMessageBox with the provided title and message.

Arguments: - title: The title of the message box. - message: The message to be displayed in the message box.

toggle_filter(filter_on: bool) → None¶

This method toggles the display of the filter widgets to indicate to the user whether or not filtering is currently taking place.

Arguments: - filter_on: Boolean indicating if filtering is on or not.

user_interface.manage_data.load_data() → tuple[dict, dict]¶

Populates a client dictionary and an account dictionary with corresponding data from files within the data directory. :returns: tuple containing client dictionary and account dictionary.

user_interface.manage_data.update_data(updated_account: BankAccount) → None¶

A function to update the accounts.csv file with balance data provided in the BankAccount argument. :param updated_account: A bank account containing an updated balance. :type updated_account: BankAccount
